## 1. Nature of the Software
The HQE Agent Skill is an open-source, instruction-based reasoning framework and capability suite designed for software repository audits, static code analysis, vulnerability discovery, architecture review, and structured remediation. The skill operates entirely within the execution runtime provided by your host AI environment (e.g., Antigravity, Kimi Code, Claude Code, Cursor, Roo Code).
