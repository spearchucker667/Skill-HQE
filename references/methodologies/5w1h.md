# 5W1H Methodology

> **Source lineage:** HQE-Workbench `mcp-server/prompts/server/resources/methodologies/5w1h/`. Paraphrased for HQE Skill use.

## Purpose

5W1H is a comprehensive questioning framework used to gather requirements, decompose ambiguous problems, and ensure no critical dimension is overlooked. It is especially useful when the problem or task is underspecified.

Use 5W1H during requirement analysis, incident triage, defect decomposition, and planning when stakeholders, scope, timing, context, motivation, or method are unclear.

## Phases / Steps

| Question | What to Capture | Required |
| :--- | :--- | :--- |
| **Who** | Stakeholders, actors, roles, and affected parties. | Yes |
| **What** | Objectives, deliverables, and success criteria. | Yes |
| **When** | Timing, deadlines, milestones, and sequence. | Yes |
| **Where** | Location, environment, platform, and contextual constraints. | Yes |
| **Why** | Purpose, motivation, and importance. | Yes |
| **How** | Methods, approaches, and implementation strategy. | Yes |

Optional follow-ups include Validation and Dependencies.

## Judge-Prompt Guidance

When reviewing a 5W1H-shaped artifact, verify:

1. **Stakeholder completeness** — all relevant actors are identified and their roles defined.
2. **Objective specificity** — deliverables are specific and measurable.
3. **Timing comprehensiveness** — the timeline is realistic and includes dependencies.
4. **Context thoroughness** — environmental and situational constraints are captured.
5. **Purpose depth** — underlying motivations are explored, not just surface goals.
6. **Method practicality** — the implementation approach is actionable and resource-aware.

## Example Usage in an HQE Workflow

When triaging an ambiguous bug report, apply 5W1H as follows:

- **Who:** Which user roles, services, or components are involved?
- **What:** What is the exact deviation from expected behavior?
- **When:** When did it start, and under what load or lifecycle phase?
- **Where:** Which code path, environment, or deployment exhibits it?
- **Why:** Why is this defect critical to the system's contract?
- **How:** How can it be reproduced in an isolated fixture?

Use the answers to populate `templates/finding.md` and to scope the remediation plan.
