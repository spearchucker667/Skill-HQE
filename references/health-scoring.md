# Health Scoring Rubric

The evidence-backed 1-10 health score uses these bands:
* 9-10: Production-ready
* 7-8: Solid
* 5-6: Fragile
* 3-4: Unstable
* 1-2: Broken

Rules:
- Allowed evidence only.
- Prohibition on fabricated percentages.
- Minimum number of supporting reasons required.
- Blocking CRITICAL issues constrain the score to <= 4.
- If coverage is insufficient, health score is omitted.
