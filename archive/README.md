# Skill-HQE Historical & Deprecated Archive

This directory stores historical assets, deprecated workflows/templates, and legacy release snapshots retained solely for provenance, reproducibility, and audit trail records.

> [!CAUTION]
> Files in `archive/` are **obsolete or historical materials**. They must **never** be referenced or loaded by runtime skill execution routines, and they are strictly excluded from distribution packages.

---

## Archive Taxonomy

| Subdirectory | Purpose |
| :--- | :--- |
| [`historical/`](historical/) | Superseded protocol revisions, legacy notes, and historical documentation. |
| [`deprecated/`](deprecated/) | Deprecated workflows, templates, or helper scripts no longer active in v5.0.0. |
| [`old-releases/`](old-releases/) | Historical release notes and deprecated packaging manifests. |
